# CRUD API

Uma API CRUD desenvolvida com Node.js, Express e TypeScript.

## Sobre o Projeto

Esta API permite realizar operações básicas de CRUD:

- Criar dados
- Listar dados
- Listar dados por ID
- Atualizar dados por Id
- Remover dados por ID

Projeto criado para estudos de desenvolvimento backend utilizando TypeScript e Express.
